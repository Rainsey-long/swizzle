# Swizzle

A repository for iOS development focusing on method swizzling techniques and UI components.

## Overview

This repository contains Swift code samples and components for iOS app development, including:

- Custom UI components
- Method swizzling examples
- UIKit extensions

## Getting Started

Clone the repository and open the Xcode project to get started:

```bash
git clone https://github.com/Rainsey-long/swizzle.git
cd swizzle
```

## Features

- Modern Swift UI implementations
- Custom chart components
- iOS utility classes

## Requirements

- iOS 14.0+
- Xcode 13.0+
- Swift 5.5+
